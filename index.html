HAZ SCROLL PARA COMENZAR

¿Puede un algoritmo convertirse en un colaborador creativo en lugar de reemplazar al músico?

Para explorar esta idea nace Magenta, un proyecto de código abierto de Google Brain que usa machine learning para investigar nuevas formas de crear música y arte. Su objetivo no es reemplazar al artista, sino ampliar sus posibilidades creativas: explorar melodías, estructuras y ritmos de maneras que antes no eran posibles.

Una década de evolución

De un laboratorio de investigación a un modelo que responde mientras tocás. Usá las flechas para recorrer los hitos.

2016

Nace Magenta

Douglas Eck funda el proyecto dentro de Google Brain para investigar el cruce entre inteligencia artificial y creatividad

2017

NSynth

Una red neuronal aprende a combinar el timbre de distintos instrumentos y genera sonidos que no existían antes

2018

Piano Genie

Ocho botones numerados bastan para improvisar en un piano completo, sin necesidad de saber tocarlo

2019

Magenta Studio

Los modelos salen del laboratorio en forma de plugins gratuitos para Ableton Live

2023

MusicLM

Google explora la generación de música a partir de simples descripciones de texto

2025

Magenta RealTime

Primer modelo abierto que genera audio en streaming, con unos 3 segundos de respuesta

2026

Magenta RealTime 2

La latencia baja a 0,2 segundos y el modelo corre en dispositivos locales, como una laptop

Piano Genie

Tocar el piano tradicional requiere años de práctica para dominar una interfaz de 88 teclas. Piano Genie, un modelo de Magenta, actúa como traductor entre la persona y el instrumento: reduce el teclado a ocho botones numerados y decide, en tiempo real, qué tecla suena mejor para cada uno.
